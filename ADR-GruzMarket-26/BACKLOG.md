  1. Артём: создать бота у @BotFather → токен; узнать chat_id (бот @userinfobot).
  2. Артём: создать Google-таблицу «Заявки GruzMarket», сервис-аккаунт в
     Google Cloud Console, выдать ему доступ редактора к таблице.
  3. Артём: Cloudflare аккаунт → `cd worker && npx wrangler deploy` +
     4× `wrangler secret put` (команды в шапке wrangler.toml).
  4. Ассистент: прописать URL воркера в `PUBLIC_LEAD_ENDPOINT` (env сборки).
  До этого форма работает через WhatsApp-фолбэк (уже живая, не заглушка).

- [ ] **AI-ассистент маркетинга (3 уровня, нарастающе).** Задача: не лазить в
  5 кабинетов (Андата + Метрика + Директ + Авито + Sheets с заявками), получать
  готовый анализ и действия. Запуск **через 2+ мес после боевого сайта**, когда
  накопятся данные.
  - **Уровень 1 — Daily brief** (Cloudflare Worker с cron trigger, ~300 строк
    кода, 0 ₽/мес на free tier). Раз в сутки дёргает API Метрики / Директа /
    Андаты (если дадут — у корп-тарифов обычно есть) / читает лист заявок,
    пушит в Telegram сводку: заявки, источники, стоимость, топ-страницы,
    аномалии («лендшафт 3 дня без заявок»). Таиров принимает решения сам.
  - **Уровень 2 — Еженедельный агент-аналитик.** Scheduled Claude-сессия
    (`mcp__claude-code-remote__create_trigger`) открывает все данные,
    строит гипотезы, присылает в Telegram **предложения с кнопками**
    (✅ применить / ❌ пропустить / 💬 обсудить). При подтверждении — через
    API Директа меняет ставки, добавляет минус-слова, стопает кампании.
    Писать когда соберём статистику по заявкам (3+ мес), есть что
    анализировать.
  - **Уровень 3 — Автономный агент** в рамках бюджета (например 30k ₽/мес):
    крутит сам, присылает отчёты. 6+ мес после MVP, когда доверие к агенту
    накопится и ошибка в 3-5k ₽/мес на эксперимент — приемлема.
  - **ВАЖНО:** Андата сама по себе уже AI-агент под Директ — наш агент
    поверх неё работает как **аналитик-штурман**, а не ML-модель ставок
    (её не перебьём). Ценность — консолидация 5 кабинетов и предложения
    в человекочитаемом виде.
  - **При подключении Андаты** (шаг TODO): запросить у их саппорта доступ к
    API и документацию — от этого зависит архитектура уровня 1.

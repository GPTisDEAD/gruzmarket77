# ADR-011: Quality gate — проверка контактов перед деплоем

**Status:** Accepted · 2026-10-01

## Context
Корпоративный сайт с мёртвой кнопкой «Позвонить» или чужим номером — потеря
доверия B2B мгновенно. На 34 HTML-страницах — 119 `tel:`, 70 `wa.me/`,
37 `mailto:` ссылок (суммарно 226). Ручная проверка исключена, а при любой
правке `company.json` → все страницы перерендериваются → нужен автомат.

Второй класс дефектов: заглушки типа `href="#"`, `TODO`, «в разработке»
могут случайно уйти в прод при копипасте компонентов.

Рассмотрены:
- **A. Полагаться на TypeScript / схему контента** — ловит типы, не ловит
  факт корректности телефона в HTML.
- **B. Astro Check** — проверяет компоненты, не финальный HTML.
- **C. Postbuild скрипт сканирует dist/ — выбран.**

## Decision
**`scripts/check-contacts.mjs`** — Node-скрипт, запускается после `npm run build`,
сканирует `dist/**/*.html`:
1. Все `tel:` — должны быть ровно `tel:+79266143959` (из `company.json`).
2. Все `href="https://wa.me/..."` — должны начинаться с `wa.me/79266143959`.
3. Все `mailto:` — ровно `mailto:tgk-777@mail.ru`.
4. Пустые `href="#"`, `href=""` в кликабельных `<a>` — проваливают билд.
5. Маркеры заглушек в видимом тексте: `TODO`, «в разработке», `XXX-`,
   `placeholder-text` — проваливают билд.
6. Телефоны в тексте в формате `+7 XXX XXX-XX-XX` — должны совпадать с
   `company.phone_tel` (ловит захардкоженные чужие номера, забытые от шаблонов).

Выход: `exit 0` если всё чисто, `exit 1` с перечнем проблем — ломает CI.

**Шаг workflow для подключения в CI (пока ручной запуск, автоматизация в BACKLOG):**
```yaml
- run: node scripts/check-contacts.mjs
```

## Consequences
**Плюсы:**
- 226 контактных ссылок проверяются за <1 сек.
- Защищает от регрессий при правке контента и шаблонов.
- Легко расширить (новые маркеры, доп. правила).

**Минусы:**
- Сейчас запускается вручную (`node scripts/check-contacts.mjs`),
  в CI не подключён. BACKLOG: добавить шаг в deploy.yml перед артефактом.
- Проверяет только прописанные правила. Семантические ошибки
  («у нас ночь +25%, в тексте «+30%») не ловит — это дело content review.

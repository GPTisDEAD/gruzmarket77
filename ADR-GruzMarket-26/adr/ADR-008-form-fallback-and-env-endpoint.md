# ADR-008: Форма — рабочий фолбэк + переключение на воркер через env

**Status:** Accepted · 2026-10-01

## Context
Форма заявки собирается на сайт **до** деплоя Cloudflare Worker (воркер требует
ключей Telegram+Sheets от Артёма — ADR-002 только описывает архитектуру, деплой
отложен в BACKLOG).

Проблема: если собрать сайт с «мёртвой» формой (POST в несуществующий endpoint
→ ошибка в консоли, пользователь уходит), E-E-A-T и доверие падают. Нельзя.

Рассмотрены:
- **A. Скрыть форму до деплоя воркера** — на сайте остаются только `tel:` и
  WhatsApp-кнопки; теряем конверсию из тех, кто хочет описать задачу текстом.
- **B. Форма через mailto:** открывает почтовик, слишком архаично для B2B 2026.
- **C. Форма с WhatsApp-fallback и env-переключением на воркер — выбран.**

## Decision
Компонент `LeadForm.astro` имеет **два режима**, переключаются переменной
сборки `PUBLIC_LEAD_ENDPOINT`:

**Режим 1 (сейчас, по умолчанию):** `PUBLIC_LEAD_ENDPOINT` не задан →
onsubmit открывает `wa.me/79266143959?text=<готовый текст заявки>`.
Пользователь видит заявку в WhatsApp, жмёт «Отправить» в чате.
Live-режим, не заглушка, работает из коробки.

**Режим 2 (после деплоя воркера):** в GitHub Actions задаётся
`PUBLIC_LEAD_ENDPOINT=https://gruzmarket77-lead.<sub>.workers.dev` →
форма делает `fetch(endpoint, { method: 'POST', body: formData })`,
воркер уже валидирует honeypot/rate-limit, пишет в Telegram + Sheets.
Фолбэк в WhatsApp остаётся только для случая network error.

Серверная логика (honeypot, rate-limit, delivery) — целиком в Worker (ADR-002),
не дублируется на клиенте.

## Consequences
**Плюсы:**
- Форма живая сразу, без ожидания воркера.
- Переключение режима — одна переменная env, без правок разметки.
- Все заявки до воркера приходят Таирову напрямую в WhatsApp — он их видит.

**Минусы:**
- В режиме 1 нет записи в Sheets — заявки нигде не журналируются до воркера.
  Приемлемо: до запуска воркера заявок будет мало (Таиров сам видит в чате).
- Пользователь делает лишний клик «Отправить» в WhatsApp — но это
  честно: «Открыли WhatsApp с текстом заявки», без обмана.
- UTM и `page` передаются в WhatsApp как текст — не аналитика, но контекст виден.
